# Context workspace preview

This branch reframes `/context` as a functional Context workspace rather than a standalone marketing landing page.

Core model:
- Empty state: help a new user start without manually filling everything in.
- Primary entry: Start from a document.
- Secondary entries: bring a source or start the interview.
- Populated state: show source/queue summary and continue building context.
- Context remains adjacent to the document workflow rather than competing with it.

This note is for preview/testing and can be removed before production if desired.
