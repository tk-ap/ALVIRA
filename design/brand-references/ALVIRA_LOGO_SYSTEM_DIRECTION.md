# ALVIRA Logo System Direction

**Branch:** `brand/alvira-system-refresh`
**Status:** Exploratory system direction for preview evaluation

## Objective

Evolve the existing owner-approved `ALVIRA/>` identity into a coherent logo system that visually expresses ALVIRA's role as **Context Intelligence**.

The goal is not to replace the current identity with an unrelated AI symbol. The goal is to make the existing identity more rigorous, ownable, scalable, and semantically tied to the product.

## Core Principle

ALVIRA does not need a brain, sparkle, orbit, chat bubble, generic node, or abstract "AI" glyph.

The visual idea should be **context framing**: intelligence already exists; ALVIRA provides the frame that makes that intelligence personally meaningful.

## Identity Architecture

### 1. Primary wordmark

Retain the `ALVIRA/>` lineage as the primary identity.

Use it for:
- navigation
- product shell
- account/product surfaces
- standard brand recognition

The wordmark should remain the most stable and recognizable expression of the brand.

### 2. Context mark

Develop a compact mark derived from the existing slash / angle geometry rather than inventing an unrelated icon.

The mark should suggest:
- incoming context
- framing / interpretation
- resolved understanding
- continuity / handoff

A strong conceptual direction is a pair of asymmetric planes or brackets creating a perceptual field around a central point or empty space. The empty space matters: it represents the person/context being interpreted rather than a generic AI "brain."

### 3. Editorial expression

Allow a more expressive large-format treatment for hero, campaign, launch, and editorial moments.

This can stretch, separate, crop, or spatially expand the `/ >` geometry while still resolving back to the canonical identity.

Editorial behavior should feel intentional and typographic, not like a separate logo.

## Semantic Role of `/ >`

Treat `/ >` as the active part of the identity.

Directional interpretation:
- `/` = incoming evidence, source, or context
- the space between = interpretation / context field
- `>` = resolved understanding, direction, or usable output

This should remain suggestive rather than literal. The system should feel intelligent before it feels diagrammatic.

## Living-State Behavior

The canonical logo must always work perfectly as a static mark.

In motion or interactive contexts, the active geometry may move through a subtle sequence:

**open → frame → resolve**

This can support the broader ALVIRA loop:

**Capture → Understand → Reflect → Update → Reuse**

Motion should be restrained and structural. Avoid glowing, pulsing, orbital, particle, or sci-fi effects.

## Usage Hierarchy

Use the system consistently:

- **Primary wordmark:** recognition and default navigation
- **Compact context mark:** favicon, avatar, small product state, status, loading, system presence
- **Editorial expression:** large hero/campaign moments only

Do not use multiple competing ALVIRA icons at once.

## Visual Character

The logo system should feel:
- precise
- editorial
- intelligent
- calm
- technical without becoming a developer-tool cliché
- human-aware rather than anthropomorphic

The mark should remain legible at very small sizes and should work in monochrome before relying on color.

## Color

Color should reinforce the system, not define it.

Current ALVIRA teal may be used as an active/system cue. Warm mineral tones may support human/context surfaces. The canonical mark must also work in black, white, and single-color applications.

## Avoid

Do not introduce:
- brains
- stars/sparkles
- infinity marks
- chat bubbles
- neural-network diagrams
- orbital systems
- generic hexagons
- letter-A monograms with no relationship to the existing identity
- decorative complexity that fails at favicon scale

## Preview Evaluation Criteria

A successful next-generation ALVIRA logo system should answer yes to these questions:

1. Does it still clearly belong to the existing `ALVIRA/>` identity?
2. Is it recognizable in a navigation bar and at favicon size?
3. Does the compact mark have an intelligible relationship to the wordmark?
4. Does the system subtly express context, interpretation, and continuity?
5. Can it work in static monochrome form?
6. Does it avoid generic AI-brand visual language?
7. Does it feel credible next to the Context Intelligence positioning?

## Implementation Rule

This document defines direction, not final production approval. Logo experiments should remain isolated to `brand/alvira-system-refresh` and preview surfaces until an owner-selected direction is explicitly approved for broader application.
